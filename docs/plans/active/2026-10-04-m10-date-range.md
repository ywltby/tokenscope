# M10：时间区间选择（参考 cc-switch）

- 状态：**已确认（用户 2026-10-04 指示：时间筛选参考 cc-switch，现有选择太少，缺时间区间选择）**
- 创建：2026-10-04

## 目标

时间过滤从"近 N 天预设"扩展为**区间能力**：

1. **CLI**：`summary` / `events` 新增 `--from YYYY-MM-DD` / `--to YYYY-MM-DD`（闭区间，按解析时区落日）；与 `--days` 互斥（同时给出报参数错误）。
2. **GUI**：Dashboard 时间筛选从 NSelect 预设换成 **NDatePicker（daterange，clearable）**，内置快捷项：近 7 天 / 近 30 天 / 近 90 天（ccs 同款能力）；选 null = 全部。
3. 后端统一入口 `apply_time_filter`：days 与 from/to 互斥校验、from≤to 校验、按解析时区过滤——summary 与 list_events 共用。

## 设计决策

- `SummaryOptions` 增加 `from` / `to`（`Option<String>`，YYYY-MM-DD）；解析为 `jiff::civil::Date`，非法日期报参数错误。
- 日期解释跟随解析时区（M6 链）：同一事件在 UTC 与上海时区可能归属不同日——与 M6 口径一致。
- GUI 的区间值在前端存毫秒时间戳，invoke 时**按当前时区选项**换算为 from/to 字符串（时区在设置页修改后自动跟随）。
- `--days` 保留（CLI 便捷预设 + 既有验收记录兼容）。

## 非目标

- 单日快捷按钮、相对时间表达式（"昨天"等自然语言）
- 明细页独立的时间选择（沿用汇总的区间）
