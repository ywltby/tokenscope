## 不变量（每个任务都必须保持）

- 只改 `frontend/src/styles/`、`frontend/src/App.vue`、`frontend/src/components/`、`frontend/src/views/` 的样式与模板结构；不改 `src/`、`src-tauri/`、`lib/` 下的计价、聚合、日期、缓存逻辑。
- 统计口径不变：命中率 = cache_read / (input + cache_read)；未知价格不显示为 `$0`；零 / 未知 / 加载中显示区分。

- 现有测试断言的业务语义不放宽；只因 DOM 结构变化调整选择器。
- 工作区中他人未提交的 `Settings.vue` 等改动不覆盖：开工前确认已提交或与其作者协调。

## 任务

### Task 1：token 与主题适配

- `tokens.css` 换成第二版语义色、字体栈、间距、圆角、阴影；新增 `.ts-card`、`.ts-segmented`、`.ts-pill`、`.ts-notice` 公共样式。
- `naiveTheme.ts`、`chartTheme.ts` 同步新色值；Naive Card / DataTable / Input / Select / Button / Tooltip 覆盖为同一外观（输入框 `--ts-fill` 底、无描边、32px）。
- 测试：主题测试中涉及色值的断言更新；新增一个断言 tokens 与 naiveTheme 关键色一致的用例。

### Task 2：应用壳

- 外层成为唯一滚动容器，导航 `position: sticky` 玻璃，内容从下方滚过。
- 页面切换、主题切换改为分段控件组件 `SegmentedControl.vue`（radiogroup + 方向键）。
- 测试：分段控件键盘切换、`aria-checked`；主题三态切换仍持久化。

### Task 3：汇总页头部与筛选栏

- 大标题行：标题 + 时区/日期副标题，右侧状态胶囊（已更新 / 刷新中 / 缓存数据）+ 刷新按钮。
- 筛选栏一行：来源（图标 + 文字分段）→ 维度分段 → 日期 → 时区，统一 32px。
- 来源异常、错误重试改为内联通知条，放在筛选栏下方。
- 测试：状态胶囊三态；来源异常与错误重试仍渲染且可点击。

### Task 4：指标卡

- 主读数费用 44px + 三个次读数；未计价胶囊；命中率公式进 tooltip（focus 可达）。
- 新增四类 token 分项比例条 + 图例；全 0 时空槽。
- 测试：比例条宽度按占比；全 0 不出现 NaN；未知价格仍显示未知标记。

### Task 5：卡片统一（趋势 / 聚合 / 明细）

- 三个区块统一用 `.ts-card` 头部结构；去掉行内 `margin-top: 12px`，区块间距 20px。
- 图表：去坐标轴线、柱顶圆角、圆点图例、tooltip 浮层样式。
- 表格：无竖线无外框、发丝线行分隔、40px 行高、可点击行 `›` 指示、合计行样式。
- 测试：现有表格/图表测试改选择器后全绿；行点击与 Enter 下钻不变。

### Task 6：状态横幅与设置页

- `PricingStatusBanner` 改为内联通知条样式。
- 设置页分组卡片 + "左标签右控件"行样式（在他人改动落地之后进行）。

### Task 7：验收

- 门禁：`pnpm --dir frontend typecheck`、`format:check`、`test`、`build`。
- `tauri dev` 真机走查 DESIGN.md §7 清单（浅/深色、1280×820 与 980×620、缩放、长名称、各数据状态），截图记录到 `docs/plans/active/` 下的 QA 文件。
