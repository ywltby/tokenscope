# TokenScope 隐私政策

更新日期：2026 年 10 月 10 日  
生效日期：2026 年 10 月 10 日  
适用范围：本仓库 TokenScope 桌面应用当前 0.1.0 版本的已实现功能

TokenScope 是用于查看本地 AI 编程工具使用量的桌面应用。本政策说明应用会读取什么数据、为什么使用这些数据、保存在哪里，以及哪些功能会联网。

**请特别注意：应用在首次启动、设置文件缺失、同意字段被删除或为 `false` 时，会先显示本政策并要求明确同意。** 在用户点击「同意并继续」且同意记录保存成功之前，应用不读取来源日志、不建立或读取用量缓存、不写诊断日志、不读取价格文件、不请求在线价格，也不读取或修改开机自启状态；该状态下不创建托盘常驻图标，关闭窗口会询问是否退出程序。拒绝或取消退出不会开始上述任何读取。同意记录保存在用户主目录的 `.tokenscope/settings.toml`（字段 `privacy_policy_accepted`）：把它删除或改为 `false` 会在下一次启动重新询问。

## 一、适用范围

本政策适用于 TokenScope 自身的日志读取、统计、缓存、设置和价格同步功能。

用户访问 GitHub、models.dev、OpenRouter，或安装、运行 Microsoft WebView2 时，相关服务或组件还可能按其自身政策处理数据。TokenScope 不控制这些第三方的全部行为，本政策不能代替其政策。

### 同意之前的必要处理

为了显示本政策并判断是否已有同意记录，应用在同意前仍会做以下**必要**处理，这是本政策明确允许的引导例外：

- 定位并读取用户主目录中的 `.tokenscope/settings.toml`（只读取其中的同意字段；文件损坏或无法读取时显示错误原因与「重新检查 / 退出」入口，不改写、不删除原文件）
- 加载随程序打包的界面资源、字体与本政策全文（不访问网络、不打开外部链接）
- 维护纯内存的运行状态，以及窗口与单实例所必需的系统交互

这些处理不包含读取来源日志、统计缓存、视图快照、价格文件或窗口状态，也不创建业务诊断日志。安装器、WebView2、操作系统组件以及用户主动打开的外部链接不受此闸门控制，见第五节。

## 二、读取的数据及用途

### 1. 本地会话日志

TokenScope 读取已启用来源中的会话日志，当前支持 Claude Code 与 Codex。默认来源为用户主目录中的 `.claude/projects` 和 `.codex/sessions`，也可由用户在设置中指定其他目录。当前两种来源默认启用，可以分别关闭。

这些原始日志可能包含对话、代码和其他敏感内容。TokenScope 会读取日志文件进行解析，提取统计所需的信息，包括：

- 使用时间、AI 工具和模型名称
- 会话标识及用于去重的记录标识
- 项目标识或工作目录路径
- 输入、输出、缓存读取和缓存写入 token 数量
- 用于发现日志、判断文件变化的路径、大小和修改时间

这些信息用于生成使用量汇总、请求明细、趋势图和费用估算。当前统计模型和用量缓存不以对话正文或代码正文作为保存字段。应用只读处理来源日志，不修改、移动或删除它们。

### 2. 设置与诊断信息

应用保存用户选择的来源目录、来源开关、价格同步开关、窗口关闭方式、主题、时区、颜色及窗口状态，以恢复使用偏好。

应用还生成本地诊断日志，用于记录运行状态、耗时和错误。日志可能包含本地文件路径、查询参数摘要、错误链和调用堆栈，因此不应视为匿名数据。

### 3. 公开价格数据

应用可从公开模型目录获取价格信息，在本地与 token 用量结合计算估算费用。估算结果不代表供应商的实际账单。

## 三、本地保存位置

TokenScope 自身的大部分数据保存在用户主目录中的 `.tokenscope` 目录，主要包括：

- SQLite 用量缓存及可能生成的 WAL/SHM 文件
- 模型价格快照、价格索引和用户外置价格表
- 应用设置（含隐私政策同意记录 `privacy_policy_accepted`）、视图快照和窗口状态
- 按日滚动的诊断日志（仅在同意之后才会创建）

用量缓存和视图快照可能包含项目路径、会话标识、模型、token 数量及费用估算。主题、时区和颜色等偏好还会使用 WebView 的本地存储，其实际位置由平台和运行时管理，可能不在 `.tokenscope` 目录内。

这些文件受本机用户账户和系统文件权限管理。应用没有为上述全部数据提供独立的应用级加密承诺；使用共享电脑、同步盘或第三方备份工具时，应自行评估其他人或服务是否能访问这些文件。

## 四、网络请求与数据传输

### 1. 不上传本地会话与统计数据

当前 TokenScope 自身没有向项目维护者上传本地会话日志、对话内容、项目路径、用量统计或诊断日志的功能，也没有内置账户、广告或自动使用分析/崩溃报告功能。

本段描述 TokenScope 已实现的功能，不涵盖用户主动把文件发到其他地方，或操作系统、运行时、备份工具等独立软件的行为。

### 2. 在线价格同步

**价格自动同步默认开启，但计时从用户同意隐私政策并进入业务运行开始。** 同意后约 2 分钟首次检查，此后约每小时检查一次。如果 models.dev 价格快照缺失、无法读取或其同步时间无法解析，或者距上次成功同步已满 24 小时，应用会尝试依次更新 models.dev 与 OpenRouter 的价格目录。系统休眠、网络状态和运行时间会影响实际执行时刻；设置文件读取失败时跳过自动同步。在用户同意之前，应用不会发出任何价格请求。

使用的公开接口为：

- `https://models.dev/api.json`
- `https://openrouter.ai/api/v1/models`

请求采用 HTTPS GET，应用设置的 User-Agent 为 `tokenscope`。价格同步不附带本地日志、对话、项目路径、token 用量或用户 API 密钥，也不会调用模型推理接口。

与其他网络访问一样，服务及其网络基础设施会收到 IP 地址及正常连接、请求元数据，可能按其自身政策记录请求。这与上传本地会话或用量数据不同。

用户可在设置页关闭“自动同步价格”，停止后续自动同步；关闭不会撤回已经发出的请求。关闭后仍可主动点击“同步在线价格”。未同意隐私政策时应用本来就不联网，因此无需事先手工预置开关。

离线时可使用已有价格快照或外置价格表。缺少价格的模型将显示为未知，不会因为关闭同步而上传日志换取价格。

## 五、第三方服务与运行时

- **models.dev**：提供公开模型价格目录。截至本政策更新日期，未在其首页找到独立隐私政策链接；这不代表该服务承诺不记录请求。参见 [models.dev](https://models.dev/)
- **OpenRouter**：提供公开模型价格目录。参见 [OpenRouter 隐私政策](https://openrouter.ai/privacy/)
- **Microsoft WebView2**：TokenScope 在 Windows 上使用 WebView2 显示界面。当前安装器沿用 Tauri 的默认模式，系统缺少 WebView2 时可能从 Microsoft 下载并运行安装引导程序。WebView2 及其更新、诊断受 Microsoft 的产品设置与政策约束；关闭价格同步不控制这些独立行为。参见 [Microsoft 隐私声明](https://privacy.microsoft.com/privacystatement)
- **GitHub**：托管源码、发行文件和问题反馈。用户访问仓库、下载软件或提交 Issue 时，GitHub 会按自身政策处理网站访问及用户主动提交的信息。当前 TokenScope 应用没有自动把会话或统计数据发送到 GitHub 的功能。参见 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)

## 六、用户可以如何控制数据

用户可以：

- 在首次启动（或同意记录被删除/改为 false 时）选择「不同意」并退出程序；此状态下应用不读取来源日志、不联网
- 在设置中关闭某个日志来源，或修改其目录。关闭来源不等于自动删除已有派生文件
- 关闭自动价格同步，选择是否手动联网更新价格
- 在设置中开启或关闭开机自启；此操作会相应注册或撤销系统自启动项。未同意时应用不读取也不修改自启状态
- 使用应用提供的缓存重建功能。重建会重新读取生效来源，不等同于永久删除统计数据
- 从托盘退出应用，或在 Windows 已安装应用列表中卸载
- 按下一节清理本地派生数据

关闭主窗口可能只是最小化到托盘。需要停止后台活动时，请确认已退出程序。未同意隐私政策时不会创建托盘图标：关闭窗口或按 Alt+F4 只会询问是否退出程序。

## 七、保留、删除与卸载

当前应用没有为全部缓存、设置和诊断日志统一设置固定保留期限。部分缓存可能在文件变化、版本迁移或重建时更新或清理；诊断日志按日滚动，但当前代码未设置按天数自动删除旧日志的规则。

如需删除 TokenScope 保存的数据，请先退出应用，备份需要保留的设置或外置价格表，再删除用户主目录中的 `.tokenscope` 目录。这会删除该目录内的缓存、快照、设置及诊断日志，不会删除 Claude Code / Codex 的原始日志。

WebView 本地存储、系统自启动记录及第三方备份可能需要另行处理。建议卸载前先关闭开机自启。**不要假设卸载会清空所有本地数据**；当前版本尚未完成安装、卸载后全部残留数据的完整真机验收。只要原始日志还在，重新运行并启用对应来源后，应用可能重新生成统计缓存。

## 八、反馈与联系方式

可通过 [项目 Issues](https://github.com/ywltby/tokenscope/issues) 联系维护者。Issue 是公开的，请勿在其中提交原始会话日志、密钥、完整个人路径或未经脱敏的截图。

请只提供定位问题所必需的信息，发送附件前自行检查并脱敏。若需要提供敏感信息，请先与维护者协商合适的非公开联系渠道，不要直接附在公开 Issue 中。

## 九、政策更新

数据处理方式发生变化时，维护者会更新本文件的日期、适用版本与内容。正式生效版本以仓库发布的政策及相应发行版说明为准。

程序内的政策展示与同意机制已经实现：首次启动（或没有有效同意记录时）显示本政策全文与「同意并继续 / 不同意」两个选择，政策全文随程序打包、离线可读；不同意时经确认可退出程序，应用不会开始读取使用数据。同意记录只保存在本机设置文件中，属于偏好记录而非防篡改的法律证明——同一用户手工把该字段写成 `true` 也会在下一次启动被接受为已知情。
