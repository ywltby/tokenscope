# 界面双语（简体中文 / 英语）实施计划

> 执行时使用 executing-plans，逐项记录实现、定向验证和交付结果。归档不表示未验项目已经通过。
> 本计划不占 N 责任编号，不改变 N01–N18 的历史结论。

**Goal:** 在不削弱隐私门禁、不改动统计口径的前提下，为界面提供 zh-CN / en-US 双语与可扩展的语言机制，并把语言偏好持久化到 `settings.toml`。

**Architecture:** 前端用 `vue-i18n`（composition 模式）集中管理消息资源；`lib/translate.ts` 只承载语言 ref + composer + 翻译入口（**不引 naive-ui / Tauri**，供纯函数库安全复用），`lib/i18n.ts` 承载 Naive UI 语言映射与设置持久化。后端新增 `settings.toml` 的 `language` 字段与 `settings_set_language` 命令（受隐私闸门保护），托盘菜单按同一字段渲染并在保存后重建。

**Tech Stack:** Vue 3 + vue-i18n 11、Naive UI、Rust（tokenscope-core settings + tokenscope-app commands/tray）。

## 1. 不变量

1. **默认简体中文**：字段缺失、读取失败、非法值一律按 `zh-CN` 解释；旧设置文件不被语言功能改写。
2. **同意前零持久化**：语言可以在隐私弹窗内于内存中切换，但不得调用 `settings_get` / `settings_set_language`、不得读写 `localStorage`、不得启动业务采集或绕过免费门禁（既有 `consent_screen_*` 断言继续成立）。
3. **同意后保存**：用户在弹窗内的选择在同意成功后写入设置（先写后读权威值），失败不阻断进入主应用，错误在设置页可见。
4. **语言与统计时区分离**：语言只影响界面文案、Naive UI 组件语言与 `html[lang]`；时间范围、时区换算、数据库键、token 与费用计算完全不变。日期显示可按语言本地化，但不得改变任何边界。
5. **法律文本保持准据语言**：隐私政策与用户许可协议正文仍是简体中文原文（离线可读、无外链），英文界面显式标注实际语言与法律效力，不冒充已翻译。
6. **技术标识不翻译**：模型名、路径、第三方来源名（models.dev / OpenRouter）、`history.db`、`USD / 1M token`、后端诊断原文与 IANA 时区名原样透传。

## 4. 布局与可访问性检查

- 英文文案比中文长：设置页左侧导航固定 168px、下拉宽度 160–200px、聚合维度分段控件均按内容自适应；`DateRangeSelect` 触发器有 220px 上限并按需省略，悬停 `aria-label` 给完整范围。
- 主题（浅色/深色）不因语言变化：语言只替换文本，不新增颜色或材质；`title` / `aria-label` 与可见文案同源。
- 键盘路径：语言下拉是 Naive `NSelect`（原生键盘可达），隐私弹窗内的语言选择同样如此；未新增只依赖 hover 的交互。
- 窄窗口：分区导航在 ≤1100px 切为顶部分段控件（既有行为），英文分区名（General / Sources / Usage data / Pricing / Appearance / Advanced）不触发截断。

## 5. 安装器中英支持评估（结论）

当前 `src-tauri/tauri.conf.json` 的 NSIS 仅声明 `English`，安装与卸载在 CI 与本机验收中一律以 `/S` 静默执行（`scripts/installer_helpers.ps1`、`scripts/test_install.ps1`）。**本轮不改变安装器语言集合**：

- 加入 `SimpChinese` 会让交互安装出现语言选择对话框，而静默安装的默认语言取决于语言列表顺序；这会影响现有五场景安装矩阵与连续升级链的判定基准，需要单独一轮真实 Runner 取证。
- 安装器语言与产品界面语言是两条独立链路：产品内语言由 `settings.toml` 决定，不依赖安装器选择。
- 结论与后续条件：安装器双语需要"显式默认语言顺序 + 静默安装语言可断言 + 五场景/升级链复验"三件事同时具备才实施；在此之前保持单一 English，无人值守安装与升级完全不变。
