## 2. 不变量与方案

1. 模型维度聚合行只显示展示名，不附加 `›`；其他维度保持现状。保留展示名无障碍名称、模型身份 key 下钻、鼠标与 Enter/Space 激活。费用原生按钮仍仅操作费用详情，不冒泡触发行筛选。
2. 图表类别和四桶系列继续共用 `buildBarChartData` 的排序；按真正绘制的模型类别与当前缩放范围计算可见行数，不以原始汇总行数或百分比粗略乘积代替离散边界计数。
3. 模型图每个可见类别至少 24 CSS px，另加坐标轴与上下留白；不再受 480px 上限限制。模型纵轴 `interval: 0`、不隐藏重叠标签，长名只横向省略，tooltip 保留全名。按日、应用、项目沿用现有布局。
4. dataZoom 后按同一行高收短；「显示全部」恢复完整模型数和高度。普通滚轮仍滚动页面，Ctrl+滚轮与滑块保留。
5. 尺寸更新沿用既有 `applyHeight` / `flushChart` / 实际尺寸缓存路径；同尺寸不重复 resize，不在 ResizeObserver 中重新派发缩放。初始化、数据刷新、维度切换、主题/语言重建、隐藏页恢复均需采用一致的行数口径，保持筛选动画。
6. 更新 `DESIGN.md`，明确模型维度例外及聚合模型行无箭头；不重设其他设计规则。

## 4. 证据与结果

### 4.1 红绿与实现

- 修复前先运行两组件定向测试：6 条新增断言红（名称尾随箭头、20/40 模型高度不足、自动跳标签、缺少 datazoom 布局监听），48 条既有测试绿。
- `UsageTable.vue` 仅对 `by=model` 去掉箭头节点，未改行激活与费用按钮事件处理。
- `TrendChart.vue` 复用真正传给轴/系列的分类数据，模型图按范围两端的离散索引计数并保留全部标签；百分比模式按新类别集合重新投影，value 模式按 ECharts 的窗口平移/跨度规则限于新集合。主题重建后用户再次缩放，会从公开事件更新端点模式，不误信旧 `getOption().rangeMode` 配置。
- 所有 init/重建路径接入同一缩放布局监听，沿用尺寸缓存与隐藏期 pending；不在 observer 中派发缩放，不新增实例重建。普通 wheel 捕获时只停止交给 ECharts，不调用 preventDefault，保留原生页面滚动；Ctrl wheel 保留。
- 同步 `DESIGN.md` 的模型行无箭头例外、模型行高与标签规则，按日/应用/项目不改布局。
