## 5. 隐私与离线

| 项 | 步骤 | 通过标准 |
| --- | --- | --- |
| 5.1 只读源目录 | 运行期间对照 `~/.claude`、`~/.codex` 目录 mtime | 源日志文件无任何写入 |

| 5.3 离线启动 | 断网启动并查询 | 统计正常（价格走本地快照；无快照时费用显示未知并提示联网同步，无内置兜底）；仅同步明确失败并可见 |
| 5.4 关闭自动同步 | 关闭开关 + 断网运行 24h 模拟 | 无联网尝试（日志无同步记录）；设置损坏时默认离线（D3）；未同意时本来就不产生任何价格请求 |
| 5.5 普通测试不触碰真实数据 | 全部数据、历史及价格路径注入临时目录；只读记录真实业务文件前后摘要 | cache/history/价格/设置及存在的 WAL/SHM 均不因测试改变；禁止为验证清理或打开真实库写连接 |

| 5.7 同意的落盘顺序与重启 | 点「同意并继续」→ 观察原子保存与首次业务读取的顺序 → 重启 | 先出现 `privacy_policy_accepted = true` 再解锁业务；重启不再询问；删除字段或改 false 后重新询问（原生场景 `privacy-accept-restart`） |
| 5.8 拒绝与退出路径 | 点「不同意」→ 取消 → 再点「不同意」→ 退出程序 | 不读已记忆的关闭动作、不最小化、无托盘残留、不写同意记录、不做窗口状态最终保存 |
