# TokenScope 隐私政策

更新日期：2026 年 10 月 28 日\
生效日期：2026 年 10 月 28 日\
适用范围：TokenScope 桌面应用程序当前版本所提供的全部功能（共同同意修订号：3）

欢迎使用 TokenScope 桌面客户端（以下简称“本应用”或“TokenScope”）。TokenScope 是一款专注于本地 AI 编程工具使用量统计、成本核算与效能分析的开源桌面应用程序。我们高度重视用户的个人隐私与数据安全，严格遵守《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》等法律法规及行业通用隐私合规最佳实践，始终践行“本地优先（Local-First）、最小必要（Data Minimization）、公开透明、自主可控”的基本原则。

本政策旨在向用户（以下亦称“您”）说明本应用在运行期间处理数据的类型、范围、目的、存储方式、网络通信机制以及您所享有的控制权。本政策以简体中文版本为唯一准据语言与法律效力依据。请在使用本应用前认真阅读并充分理解本政策的全部内容。关于本软件的使用许可、无担保声明、商业账单免责及开发者责任限制等实体权利义务，请参阅独立的 [TokenScope 最终用户许可与免责协议](terms.md)。

### 特别重要提示：前置知情同意合规机制
本应用严格实行“先授权、后处理”的前置准入机制。在用户首次运行本应用、本地配置文件缺失、授权记录无效，或隐私政策、用户许可协议更新后，应用将提供两份文件并请求用户明确同意。点击“同意并继续”同时确认隐私政策与用户许可协议；在形成有效同意记录之前，本应用保持静默，不开展以下处理：
- 不访问、扫描或解析任何第三方 AI 工具的本地会话日志；
- 不创建或读取本地用量历史数据库及缓存索引；
- 不生成本地运行诊断日志；
- 不发起向外的网络请求（包括公开模型价格同步）；
- 不调用系统接口查询或变更开机自启动配置项；
- 不驻留系统托盘，用户关闭窗口时提示退出程序。
若用户选择拒绝或不同意本政策，可随时退出应用程序，本应用不会在用户设备上启动任何业务数据处理流程。

## 一、适用范围

本政策适用于 TokenScope 桌面应用程序及其内置的全部功能模块，涵盖本地会话日志扫描与解析、Token 消耗统计、费用测算、系统配置管理及在线价格快照同步等功能。

### 1. 第三方服务与运行环境的独立性
本应用在运行期间涉及公开数据源（如 models.dev、OpenRouter）、开源代码托管与议题反馈平台（如 GitHub）及底层操作系统依赖组件（如 Microsoft WebView2）。前述第三方平台与组件均独立运行，分别受其自主公布的隐私政策与服务协议管辖。TokenScope 不控制亦不对该第三方的独立数据处理行为承担任何法律责任。用户在访问或使用相关第三方服务前，应当独立审阅其隐私声明。

### 2. 授权同意前的最小必要引导处理
为向用户完整呈现本政策并依法核验授权同意状态，本应用在用户作出同意决定前，仅执行维持基础引导界面运行所必需的最小本地操作：
- 读取本地配置目录中用于记录授权状态的特定字段，以确认是否存在有效的历史同意记录；
- 离线加载随应用程序二进制文件打包的界面基础组件与本政策正文文本（由本地离线渲染，不产生网络流量）；
- 维护基础引导窗口显示及进程生命周期管理所必需的纯内存状态。
前述引导阶段的处理仅限于本地易失性内存及专属配置路径，不涉及对第三方工具日志的读取、用量数据的提取或外部网络的访问。

## 二、读取的数据及用途

本应用严格遵循合法、正当、必要和诚信原则，仅在实现本地统计分析功能所必需的最小限度内，以纯本地、只读方式处理相关数据。

### 1. 本地 AI 编程工具会话日志（纯本地只读分析）
TokenScope 目前支持对以下本地 AI 编程工具生成的会话转写记录进行统计：Claude Code、Codex、WorkBuddy（国内版）以及 WorkBuddy AI（国际版）。本应用仅在用户已明确启用的来源目录范围内执行读取：
- 默认数据根目录：各受支持工具在用户本地主目录下的标准项目或会话转写目录；
- 环境变量派生根目录：由当前运行环境显式声明的绝对路径目录（如 `CODEX_HOME`、`CLAUDE_CONFIG_DIR`）；
- 用户自主配置目录：用户在应用设置中根据实际开发环境主动添加并启用的本地指定目录。

在解析已启用的日志文件时，本应用仅提取并处理与使用量统计直接相关的结构化元数据：
- 事件时序信息：请求发生与记录生成的时间戳，用于时序聚合与用量趋势分析；
- 工具与模型标识：AI 编程工具类型及调用的模型名称或等价标识，用于维度分类统计；
- 会话与去重标识：会话标识（Session ID）及记录唯一编号，仅用于实现幂等去重与记录对账；
- 项目归集标识：规范化项目根路径或工作目录标识，用于项目维度的聚合核算；
- Token 用量指标：输入、输出、缓存读取及缓存写入的 Token 计量数值，用于测算用量规模；
- 文件基础元数据：日志文件物理路径、文件大小及最后修改时间戳，仅用于校验文件变动与实现增量统计，不用于任何用户行为分析或活动画像。

数据处理豁免与红线条款：
- 排除对话正文与交互内容：本应用不提取、不转录、不解析亦不留存用户的任何提问提示词（Prompts）、对话正文及模型生成回复；
- 排除代码资产与工程文件：本应用不扫描、不读取、不转储亦不备份用户的源代码文件、版本提交差异（Diff）或文件上下文快照；
- 排除敏感凭据与扩展文件：严格限定各客户端的数据读取边界。以 WorkBuddy 系列工具为例，仅限于只读解析其本地会话转写文件（`*.jsonl`），明确排除其内部关系型数据库（`workbuddy.db`）、调用追踪详情（`traces/`）、代码版本历史（`file-history/`）、包含 API 密钥等敏感认证信息的配置文件（`models.json`），以及仅存储于其云端服务端的会话数据；
- 系统级只读访问：对来源日志文件的访问均采用操作系统只读（Read-Only）模式，不会对原始数据文件实施写入、修改、移动、截断、覆盖或删除操作。

### 2. 应用配置与本地运行诊断信息
- 本地配置参数：在获得授权后，本应用在本地持久化记录用户的操作偏好，包括已启用的日志来源、统计时区、查询区间、窗口关闭响应模式、界面主题以及价格同步配置等，旨在维持软件运行状态的连贯性；
- 本地运行诊断日志：为保障系统运行稳定性并辅助故障定位，本应用在获得授权后按日于本地生成滚动日志，记录初始化耗时、命令调用摘要及异常错误堆栈。该日志仅存留于本地，绝不主动外传；因日志可能包含本地系统路径片段，用户向第三方提供诊断信息时应当自行完成脱敏。

### 3. 公开模型基准价格数据
本应用通过本地文件或公开网络端点获取 AI 模型标牌单价，用于在用户本地计算设备上结合 Token 消耗量估算使用成本。所有计费推演均在本地执行，测算数值仅供参考，不构成任何商业服务提供商的正式账单或结算凭据。

### 4. 第三方本地用量数据的手动导入机制
本应用提供从第三方本地工具（如 cc-switch）单向导入历史用量数据的辅助功能，该功能严格受制于以下合规边界：
- 严格以用户主动指令为前提：仅在用户主动发起导入后，本应用方以只读模式访问指定的外部本地数据库——点击「预览」即会只读打开该库读取概要（本应用自身历史库若缺失或为旧版，可能在此阶段被创建或迁移），确认导入后才写入导入结果；**拒绝确认不写入任何导入用量**；
- 严格限定字段白名单：仅提取时间戳、工具标识、模型名称、Token 计数及原始费用等核算必需字段，不读取亦不存留任何身份凭证、API 密钥或网络服务配置；
- 静态单次合并原则：导入行为仅作为单次静态合并操作执行，不建立后台持久化文件监听，不执行周期性自动同步。

## 三、本地保存位置

TokenScope 秉持“数据归属用户本地”的架构设计，本应用产生及维护的全部数据文件集中存储于用户本地计算机主目录的专用文件夹（`.tokenscope`）内：
- 统一本地用量历史数据库：采用 SQLite 数据库格式（`history.db` 及关联日志文件），用于持久化保存从各来源提取的 Token 统计事件、来源索引与去重证据；
- 模型价格快照与索引：用于离线计算估算花费的价格配置文件及缓存索引；
- 应用配置文件：包含用户设置项、隐私政策授权记录及窗口偏好；
- 本地诊断日志：按日滚动的文本运行日志。

此外，界面主题与视图状态等轻量级视觉偏好可能保存在操作系统 WebView 容器的隔离存储区域中。

本地数据安全与系统权限责任边界：上述本地文件均依托底层操作系统的用户账户权限与自主访问控制（ACL）机制实现访问隔离。本应用未在操作系统之上附加独立的应用层专用加密算法。鉴于此，若用户设备处于多用户共享使用环境，或启用了第三方云同步网盘、自动备份工具，用户应当审慎评估物理设备访问权限及第三方云端存储的安全性，防范数据被非授权第三方访问的风险。

## 四、网络请求与数据传输

### 1. 本地会话与统计数据无远程上传
本应用不包含将用户本地会话日志、对话内容、源代码、工作区路径、Token 统计报表或诊断日志向远程服务器或第三方机构传输的功能。应用内部不设立远程用户账户体系，不投放商业广告，亦未集成第三方用户行为追踪或自动崩溃回传组件。数据处理流程限定于用户本地设备。

### 2. 在线模型价格目录同步机制（极窄范围的只读查询）
为便于核算最新的模型费用，本应用内置了公开价格目录的同步能力，网络请求遵循最小必要原则：
- 触发时机与前置条件：价格同步仅在用户已明确同意本政策的前提下运行，并分两种方式——保持开启“自动同步价格”时按设定周期自动运行，或由用户在设置页随时主动点击“同步在线价格”手动触发；关闭自动同步仅停止自动周期，不禁用上述手动入口。在获得用户授权（同意本政策）前，应用不会发起任何外部网络连接；
- 目标请求端点：通过标准传输层加密协议（HTTPS GET）直接访问以下公开模型价格数据源：
- `https://models.dev/api.json`
- `https://openrouter.ai/api/v1/models`
- 请求载荷最小化：网络请求仅声明标准 HTTP 标头（User-Agent 声明为 `tokenscope`）。请求中不包含本地日志片段、Token 消耗量、项目路径、会话标识、设备指纹或用户 API 密钥；本应用亦不调用模型推理接口；
- 底层连接元数据说明：与通用网络通信协议一致，提供公开价格目录的服务端及其承载网络可能会记录访问端的 IP 地址、请求时间等基础网络日志。该记录由第三方服务端依据其独立规则处理；
- 离线运行保障：用户可随时在应用设置中关闭“自动同步价格”。关闭后，本应用**不再自动发起**价格同步请求；用户在设置页**仍可主动点击“同步在线价格”**手动发起一次请求。两种状态下统计功能都可依托本地既有价格快照或用户自定义价格表运行。

## 五、第三方服务与运行时

## 六、用户可以如何控制数据

作为自身设备与数据的主体，用户对 TokenScope 中处理的数据享有知情与自主决定权：
- 授权许可与拒绝权：在首次启动或政策重大修订时，用户有权拒绝授权并退出程序。在未获得授权时，本应用保持静默，不读取本地日志，亦不进行网络访问；
- 数据来源自主配置权：用户可随时在设置中启用或停用任一 AI 工具来源（如单独停用 WorkBuddy 或 Codex），亦可自由添加、启停或移除手动追加的工作目录；
- 网络通信自主阻断权：用户可自主关闭自动价格同步，阻断本应用向外部公开价格接口发起的一切常规查询；
- 开机自启项管理权：用户可在设置中自主启用或注销开机自启动项，本应用仅在获得明确指令后方调用操作系统接口变更自启动配置；
- 本地统计缓存重建权：用户可随时触发本地缓存与历史数据库的重新扫描与校验，应用将按最新规则重新生成统计视图；
- 随时退出与程序卸载权：用户可随时通过托盘菜单或窗口操作退出应用进程，亦可通过操作系统的程序管理功能卸载本应用。

## 七、保留、删除与卸载

### 1. 数据保留机制
本应用产生的全部本地用量事实库、用户设置与诊断日志均物理保留于用户本地设备。只要用户未主动执行删除或清理操作，该等数据将持续保存在本地，以供用户持续追溯历史用量与成本趋势。

### 2. 本地数据的清理与删除
若用户决定终止使用本应用并清理相关本地数据，可按以下方式处理：
- 首先通过系统托盘或任务管理器退出 TokenScope 进程；
- 若已启用开机自启动，建议在退出前于应用设置中注销该配置项；
- 直接删除用户主目录下的 `.tokenscope` 专属文件夹。
删除该文件夹后，TokenScope 存储的用量历史库、缓存、配置项、隐私授权记录及本地诊断日志将被清除。

### 3. 与第三方原始日志的边界说明
需要说明的是，TokenScope 对第三方 AI 编程工具的会话日志仅具备只读访问权限。删除 TokenScope 的本地数据目录或卸载本应用，不会删除或影响 Claude Code、Codex、WorkBuddy 等工具在其自身目录下保存的原始数据。若用户希望彻底清除这些第三方工具的原始日志，请参照各工具对应的官方指引在其原生目录中进行清理。

### 3. 准据语言与版本效力
本政策以简体中文书就并以简体中文文本为唯一有效依据。即便未来向用户提供任何其他语言（如英语等）的翻译版本，该翻译文本亦仅供用户阅读与理解参考，不具备正式法律效力。若不同语言版本之间存在任何理解分歧、含义冲突、歧义或不一致，在任何情况下均以简体中文版本为唯一权威文本，并具有排他性法律效力。
