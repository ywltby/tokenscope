# 控件材质与浮层可读性计划：按钮边界、焦点与操作浮层

> 状态：**待用户确认，未开始实施。** 第 2 节三项决策确认后交执行模型实施；确认前不改 `DESIGN.md` 和代码。
>
> 来源：用户 2026-10-13 反馈（两张截图）：
> - 暗色模式下的按钮边界不清，分不出是文字还是按钮。
> - 鼠标点击后，边缘高亮不对劲。
> - 不像磨砂玻璃；亮色模式下边缘只有一点灰。
> - 日期面板里的时刻滚轮半透明，盖在日历上，看不清数字。
>
> 要求“从顶层设计优化”，不是逐个按钮修补。

**Goal：**
- 所有可点击控件在明暗两种主题下静止时就能认出是控件。
- 焦点高亮只在键盘操作时出现，且与玻璃材质协调。
- 操作型浮层不透出下层内容。

**Architecture：**
- 在 `DESIGN.md` 的“画布 → 玻璃卡片 → 实色数据区 → 浮层”四层之外，补上缺失的第五层“**控件材质**”，并为按钮定好层级与各状态。
- `tokens.css` 新增控件 token；`naiveTheme.ts` 把 Naive 按钮、选择框、时间和日期面板的状态全部映射到这些 token。
- 手写按钮改用同一组公共类。浮层分为“操作型”（实色）和“说明型”（保留玻璃）两类。

**Tech Stack：** Vue 3 / Naive UI 2.45.3 / `tokens.css` / `naiveTheme.ts` / `frontend/scripts/check-ui-contracts.mjs`（浏览器契约）/ Vitest。

## 1. 现状事实（2026-10-13 核对）

### 1.1 根因

| 编号 | 现象 | 根因（代码位置） |
| --- | --- | --- |
| F1 | 暗色下按钮像文字 | `naiveTheme.ts` 把 `Button.border` 覆盖成 `none`，Naive 默认按钮的底色本来就是透明（`#0000`），结果“次按钮 = 纯文字”。日期快捷项另由 `DateRangeSelect.vue` 用 `--ts-separator`（8%）的细线拼接。 |
| F2 | 鼠标点击后出现一圈细蓝边、文字变蓝 | Naive 按钮在 `:focus`（而非 `:focus-visible`）下应用 `borderFocus: 1px solid primaryColorHover` 和 `textColorFocus: primary`（`naive-ui/es/button/src/styles/index.cssr.mjs:42-59`）。我们只覆盖了 `border`，没有覆盖 focus/hover/pressed 各状态，所以鼠标点一下就留下键盘焦点样式。刷新按钮另外挂了 `.ts-focusable`，键盘聚焦时两套焦点样式会叠在一起。 |
| F3 | 焦点环在浮层和卡片里显得发黑或发白 | `--ts-focus-ring` = `0 0 0 2px var(--ts-canvas), 0 0 0 4px accent`：中间那道 2px 间隙用的是**画布色**，放在玻璃卡片或浮层上会成为一道近黑（暗色）或冷灰（亮色）的色带。 |
| F4 | 暗色主按钮是浅蓝底 | Naive 主按钮的底色取 `common.primaryColor`，我们把它设成 `--ts-accent`（`#4DA3FF`，这是文字强调色），而不是 `DESIGN.md` 规定的填充色 `--ts-accent-fill`（`#0060DF` + 白字）。 |
| F5 | 时刻滚轮透出日历数字 | 时间列浮层的底色 = `TimePicker.panelColor` = `popoverColor`（85% 半透明），而 `tokens.css` 的模糊名单不含 `.n-time-picker-panel`：**半透明且无模糊**，叠在第一层浮层的日历上，数字直接透出。按设计，浮层只允许一层材质（RC09），这里却是浮层叠浮层。 |
| F6 | 悬停反而更淡 | `--ts-fill-hover` 浅色 8%、深色 16%，都**低于** `--ts-fill` 的 12% / 24%。有底色的控件一悬停，边界反而变弱。 |

### 1.2 实测对比度

计算方法：按 token 逐层合成到实际衬底后，用 WCAG 相对亮度公式求对比度。

| 组合 | 现值 | WCAG 要求 |
| --- | --- | --- |
| 暗色：日期快捷项分隔线（8% 白）/ 浮层 | **1.28:1** | 控件边界 ≥ 3:1（1.4.11） |
| 暗色：分段控件底槽 `--ts-fill` / 卡片 | **1.32:1** | ≥ 3:1 |
| 亮色：快捷项分隔线（8% 黑）/ 浮层 | **1.20:1** | ≥ 3:1 |
| 亮色：分段控件底槽 / 卡片 | **1.15:1** | ≥ 3:1 |
| 暗色主按钮：白字 / `#4DA3FF` | **2.63:1** | 文字 ≥ 4.5:1 |
| 暗色：白字 / `--ts-accent-fill` `#0060DF` | 5.62:1 | 已达标（改用它即可） |
| 亮色：白字 / `#0071E3` | 4.70:1 | 已达标 |

结论：问题不在于“玻璃不够玻璃”，而是**控件层没有定义**。卡片材质被直接套给了按钮，按钮的边界对比度只有 1.2–1.3:1。

### 1.3 涉及范围

- **Naive 按钮**：约 36 处（`Settings.vue` 20 处、`DateRangeSelect.vue` 7 处、关闭/隐私/价格横幅弹窗、`Dashboard.vue` 刷新按钮），类型有 default、secondary、primary、error、quaternary。
- **手写按钮**：
  - `.chart-reset`（“显示全部”，透明的纯文字按钮）

  - `.ts-notice-action`（文字链接）
  - 说明浮层和费用浮层的触发器（行内按钮）

## 2. 待用户确认的决策（括号内为推荐默认）

1. **D1 边界清晰度目标（推荐：严格按 WCAG 1.4.11，边界 ≥ 3:1）。**
   - 需要的描边强度：暗色约 38% 白，亮色约 44% 黑。亮色下边框会明显变重，需要靠白色凸起底面和阴影来减轻观感。
   - 备选“折中”：≥ 2:1 并加立体阴影。观感更轻，但仍可能被认为不清楚。
   - 无论选哪一种，都按截图做前后对比验收。
2. **D2 “泛光”的定义（推荐：克制的边缘受光和焦点光晕，不做霓虹）。**
   - 允许的发光：
     - 控件上沿 1px 的内高光（玻璃受光）；
     - 暗色悬停时极淡的中性外晕；
     - 键盘焦点和“当前选中”时一圈强调色柔光：不透明度 ≤ 30%，扩散 ≤ 12px。
   - 仍然禁止：彩色霓虹、持续呼吸闪烁、大面积外发光。
   - 需要同步修改 `DESIGN.md` §1 的“禁止霓虹发光”条款，写清两者的界线。
3. **D3 操作型浮层改为实色（推荐）。**
   - 改为实色：日期/时间面板、下拉菜单、时间列、颜色选择器——这些浮层里需要精确点选数字或选项。
   - 保留 85% 玻璃：说明型浮层（tooltip、帮助说明、费用明细）。
   - 卡片、导航栏、通知条的玻璃保持不变（沿用此前“玻璃风格保留现状”的决定）。

## 3. 必须保持的不变量

1. 所有业务行为不变：日期草稿/确认/取消、刷新、保存、导入、主题持久化。本计划只改外观和焦点表现。
2. 颜色只经语义 token 使用；`naiveTheme.ts` 与 `tokens.css` 同值同步，组件里不出现十六进制字面量。
3. 键盘焦点始终可见（`:focus-visible`）；鼠标点击不留焦点环，也不变色。焦点环不依赖画布色。
4. 一个浮层恰好一层材质（RC09 延续）；**浮层叠浮层时，上层一律实色**。
5. 文字对比 ≥ 4.5:1；控件边界达到 D1 选定的目标；明暗两主题都满足。
6. 尊重 `prefers-reduced-motion`：光晕和高光的过渡在该模式下关闭。
7. 不升级 Naive UI，不新增依赖。

## 4. 设计方案

### 4.1 控件材质 token（新增，明暗各一套）

暂定值以满足 D1 为准，执行时用契约脚本实测后微调，并回写 `DESIGN.md` 的表格。

| Token | 亮色（暂定） | 暗色（暂定） | 用途 |
| --- | --- | --- | --- |
| `--ts-control-bg` | `rgba(255,255,255,.92)` | `rgba(255,255,255,.07)` | 次按钮、日期按钮、选择框底 |
| `--ts-control-bg-hover` | `#FFFFFF` | `rgba(255,255,255,.12)` | 悬停（必须比静止**更强**） |
| `--ts-control-bg-pressed` | `rgba(118,118,128,.16)` | `rgba(255,255,255,.04)` | 按下：凹陷，去掉高光 |
| `--ts-control-stroke` | `rgba(0,0,0,.44)` | `rgba(255,255,255,.38)` | 静止边界（D1 = 3:1 时） |
| `--ts-control-stroke-hover` | `rgba(0,0,0,.56)` | `rgba(255,255,255,.52)` | 悬停边界 |
| `--ts-control-rim` | `inset 0 1px 0 rgba(255,255,255,.9)` | `inset 0 1px 0 rgba(255,255,255,.14)` | 上沿受光 |
| `--ts-control-shadow` | `0 1px 2px rgba(0,0,0,.10)` | `0 1px 2px rgba(0,0,0,.45)` | 抬起感 |
| `--ts-control-glow-hover` | `none` | `0 0 10px rgba(255,255,255,.06)` | 暗色悬停的中性外晕（D2） |
| `--ts-selected-bg` | `--ts-accent-soft` | `--ts-accent-soft` | 选中态底 |
| `--ts-selected-stroke` | `rgba(0,102,204,.55)` | `rgba(77,163,255,.6)` | 选中态边界 |
| `--ts-selected-glow` | `0 0 0 3px rgba(0,113,227,.12)` | `0 0 12px rgba(77,163,255,.28)` | 选中态柔光（D2 上限内） |
| `--ts-focus-ring` | 改为 `outline: 2px solid accent; outline-offset: 2px` + `0 0 0 6px` accent 18% 光晕 | 同上，光晕 24% | 键盘焦点；**删除画布色间隙** |
| `--ts-surface-popover-solid` | `#FFFFFF` | `#2C2C2E` | 操作型浮层（D3） |

- `--ts-fill-hover` 改名为表格行专用的 `--ts-row-hover`，保留原值和原语义。控件的悬停只用 `--ts-control-bg-hover`。
- 分段控件底槽 `--ts-fill` 维持填充语义，另加 1px `--ts-control-stroke` 边界。

### 4.2 按钮层级

写入 `DESIGN.md` §5，取代现有零散描述。

| 层级 | 静止外观 | 使用规则 |
| --- | --- | --- |
| 主按钮 | `--ts-accent-fill` 底 + `--ts-on-accent` 字 + 上沿受光 + 阴影 | 每个区块最多一个（确定、导入、立即同步） |
| 次按钮（默认） | 控件材质：底 + 描边 + 上沿受光 + 阴影 | 取消、重扫、打开文件、重试、恢复默认 |
| 危险按钮 | 次按钮材质 + `--ts-error` 字和描边 | 破坏性操作；只有二次确认按钮才用实心填充 |
| 文字按钮 | 无边界，**强调色文字**；悬停出现 `--ts-control-bg` 底 | 只用于行内或通知条（“去设置 ›”“详情”“清除”“显示全部”）；不得用中性色文字冒充按钮 |
| 选择型（分段、快捷项、导航项） | 底槽或控件材质；选中 = `--ts-selected-*` | 多选一；当前项必须有非颜色线索（字重 600 或选中块） |

**硬规则：** 除文字按钮外，所有按钮在静止时必须有可见边界（满足 D1）；任何按钮都不能只靠悬停才显现。

### 4.3 状态矩阵（所有按钮层级统一）

| 状态 | 表现 |
| --- | --- |
| 静止 | 按 4.2 |
| 悬停 | 底色加强、描边加强；暗色加中性外晕；**文字颜色不变** |
| 按下 | 底色变暗、去掉上沿受光（凹陷），120ms |
| 鼠标点击后的焦点 | 与静止相同（不画环、不变色） |
| 键盘焦点 | 2px 强调色描边（`outline-offset: 2px`）+ 柔光；与悬停可叠加 |
| 选中 | `--ts-selected-*` + 字重 600 |
| 加载中 | 保持尺寸，显示加载图标，禁用点击 |
| 禁用 | 不透明度 0.45，去掉阴影和外晕，文字对比仍 ≥ 3:1 |

### 4.4 浮层分类（D3）

| 类别 | 成员 | 材质 |
| --- | --- | --- |
| 操作型 | 日期范围浮层、时间列、下拉菜单（Select 菜单）、颜色选择器面板 | `--ts-surface-popover-solid` 实色 + 1px `--ts-separator-strong` 描边 + elevated 阴影；不使用模糊 |
| 说明型 | tooltip、帮助说明（`.help-tooltip-body`）、费用明细 | 保持 85% elevated + 16px 模糊（费用公式区仍套实色衬底） |
| 嵌套浮层 | 任何浮层里再弹出的浮层 | 一律实色，不得半透明 |

### 4.5 日期快捷项

- 把“用 8% 细线拼成的一整条”改为**独立的选择型按钮**：间距 4px，每项都用控件材质；当前预设显示选中态，`aria-pressed="true"`。
- “全部时间”被选中时也只用选中态，不再是实心主色块。整个面板只有“确定”一个主按钮。

## 6. 实施任务（C01–C06，每项一个提交）

### C01 token 与公共类

- `tokens.css` 落地 4.1 的 token（明暗两套，以及不支持 `backdrop-filter` 时的降级值）。
- 新增公共类：
  - `.ts-btn`（次按钮材质）
  - `.ts-btn-text`（文字按钮）
  - `.ts-choice` / `.ts-choice[aria-pressed="true"]`（选择型）
  - `.ts-popover-solid`
- 改写 `.ts-focusable:focus-visible`，焦点环去掉画布色间隙；`--ts-fill-hover` 改名为 `--ts-row-hover`。
- **测试：** 契约脚本读取计算后样式，断言明暗两套 token 存在，并断言焦点环不引用 `--ts-canvas`。

### C02 Naive 主题映射

在 `naiveTheme.ts` 里：
- **Button**：覆盖 default / secondary / primary / error / quaternary 各类型的
  - `color` / `colorHover` / `colorPressed` / `colorFocus`
  - `border` / `borderHover` / `borderPressed` / `borderFocus`
  - `textColor*`
- **焦点类值等于静止值**，键盘焦点改由全局 `.n-button:focus-visible` 画环。
- **主按钮**底色用 `accentFill`，并调整波纹颜色（`rippleColor*`），避免点击后出现蓝色扩散。
- **Select**：选择框覆盖 `border`/`borderHover`/`borderFocus`，与次按钮同材质。
- **Input**：描边改为 `--ts-control-stroke`。
- **TimePicker / DatePicker / ColorPicker / Select 菜单**：`panelColor` 改为实色，并加描边。

`common.primaryColor` 保持 `accent` 不变（链接、勾选框等文字强调仍然需要它）。

**测试：** `naiveTheme` 单元测试断言两种模式下以下各项：
- 主按钮底色 = `accentFill`；
- `borderFocus` = `border`、`textColorFocus` = `textColor`；
- 时间面板底色不透明（alpha = 1）。
